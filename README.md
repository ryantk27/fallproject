# fallproject
My fall 2026 project
"Hook"
An extension that analyzes the current webpage(both the URL and the script) you are on and generates a risk assessment basically telling you how suspicious the site looks.
By analyzing the webpage, it evaluates several indicators like;
Suspicious URL structures
Lookalike domains
Domain impersonation
Login and credential forms
External redirects
Suspicious scripts
Domain/page inconsistencies
Social-engineering language
Instead of simply telling you "This is a phishing website". It tells you WHY the page is being flagged and WHAT is being flagged for. that is; if it's 
Domain impersonation
Urgency language
Young domain
Suspicious URL
External form submission
And then finally assign a phishing likeliness score.
